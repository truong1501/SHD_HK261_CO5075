Semaphore

Binary và counting semaphore cho báo hiệu sự kiện, mutex bảo vệ Serial dùng chung.

Mã nguồn trên GitHub Báo cáo (PDF)

Tổng quan

Nút BOOT (GPIO0) là nguồn sự kiện, LED D13 (GPIO48) là đầu ra.

EnvFileCơ chế
mutex (mặc định)src/main_semaphore_mutex.cppBinary semaphore báo hiệu nút → LED, mutex bảo vệ Serial dùng chung
binarysrc/main_semaphore_binary.cppBinary semaphore: mỗi lần nhấn LED nháy 3 lần
countingsrc/main_semaphore_count.cppCounting semaphore: các lần nhấn được xếp hàng (tối đa 5)

Sơ đồ hệ thống

Kiến trúc (env mutex)

TaskƯu tiênVai trò

Heartbeat1Ghi log định kỳ qua cùng mutex Serial
pio run -e mutex -t upload
pio device monitor
[   5120 ms][BlinkLED     ] Waiting to TAKE binary semaphore...
[   7480 ms][MonitorButton] GIVE binary semaphore -> OK
[   7480 ms][BlinkLED     ] TAKE OK -> blink LED 3 times
[   8682 ms][BlinkLED     ] Blink done

Mutex của FreeRTOS có kế thừa độ ưu tiên (priority inheritance), hạn chế hiện tượng đảo ưu tiên khi các task có độ ưu tiên khác nhau cùng dùng Serial.
