I2C với DHT20

Quét bus I2C, đọc nhiệt độ/độ ẩm có xử lý lỗi, gửi lên CoreIOT qua Serial gateway.

Mã nguồn trên GitHub Báo cáo (PDF)

Tổng quan

DHT20 nối bus I2C: SDA = GPIO11, SCL = GPIO12, địa chỉ 0x38, tần số 100 kHz. Thư viện robtillaart/DHT20 được cài qua lib_deps.

Sơ đồ hệ thống

Các chương trình (chọn bằng env)

EnvFileMô tả
scan (mặc định)src/main_i2c_scan.cppQuét bus I2C 0x08–0x77, đọc DHT20 mỗi 5 s, kiểm tra mã lỗi
basicsrc/main_dht20_basic.cppTask LED + task đọc DHT20
queuesrc/main_dht20_queue.cppProducer/consumer qua FreeRTOS queue
gatewaysrc/main_dht20_gateway.cppIn mỗi lần đo thành một dòng JSON để gửi lên CoreIOT
pio run -e scan -t upload
pio device monitor          # bấm RST khi Monitor đang mở để xem lại kết quả quét
Scanning I2C bus...
  Found device at 0x38  <- DHT20
Scan done: 1 device(s)
Temperature: 29.85 C | Humidity: 61.20 %

Mã lỗi của dht20.read(): -10 checksum, -11 mất kết nối, -14 timeout, -15 đọc quá sớm (< 1 s).

Gửi dữ liệu lên CoreIOT qua Serial gateway

Board không cần Wi-Fi: máy tính làm gateway, đọc JSON qua cáp USB và publish lên CoreIOT.

pio run -e gateway -t upload
pip install -r gateway/requirements.txt
python gateway/serial_gateway.py            # tự tìm cổng /dev/cu.usbmodem*
  • Thông tin đăng nhập dùng lại CoreIOT/.env của Bài 1.
  • light là giá trị giả lập (300–500 lux) vì phần cứng không có cảm biến ánh sáng.
  • Đóng Serial Monitor trước khi chạy gateway (mỗi cổng chỉ một chương trình mở được) và không chạy đồng thời với coreiot_device.py (cùng client ID).
